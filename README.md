## Overview

This repository contains the public-facing Founder node of the PortusSophia™ research initiative.

It presents:

- Professional identity
- Research scope
- Problem framing
- Architectural positioning
- Institutional context

It does **not** contain:

- Governance artifacts
- Internal audit records
- Experimental or lab materials

Layer separation is intentional.
